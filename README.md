# Software-Test

1. How can I ensure that my code, program, or software is functional and secure?
I can ensure my software is functional and secure by using thorough testing, validating inputs and following secure coding practices. In this project, I used JUnit tests to verify that all requirements were met and that invalid data was properly rejected.

2. How do I interpret user needs and incorporate them into a program?
I interpret user needs by analyzing the requirements and translating them into program features and test cases. For example, I implemented validation rules for field lengths, unique IDs, and appointment dates because they were specified in the requirements.

3. How do I approach designing software?
I start by reviewing the requirements and breaking the system into smaller components with clear responsibilities. In this project, I separated the object classes from the service classes, which improved organization, maintainability, and testing.
